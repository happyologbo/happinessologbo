# Oboh Happiness Ologbo — Portfolio

COS 106 (Introduction to Web Technologies) term project: a responsive student portfolio and academic management website, built with plain HTML, CSS and JavaScript (no frameworks).

## Pages
- `index.html` — Home: name, photo, welcome message, biography, navigation
- `about.html` — Educational background (with a table), career goals, skills, hobbies
- `projects.html` — Four projects with images, descriptions and links, plus a working password checker
- `planner.html` — Academic planner: add, complete, filter, sort and delete tasks (saved in localStorage)
- `contact.html` — Contact form with JavaScript validation (no empty fields, valid email, digits-only phone)

## Folders
- `css/style.css` — the single external stylesheet
- `js/main.js` — shared code: menu, animations, music player
- `js/planner.js`, `js/contact.js`, `js/projects.js` — page-specific code
- `images/` — photos and the portrait placeholder (replace `profile-placeholder.svg` with your photo)
- `audio/quiet-hours.mp3` — background music

## Run it
Open `index.html` in a browser, or host the folder on GitHub Pages / Netlify.
